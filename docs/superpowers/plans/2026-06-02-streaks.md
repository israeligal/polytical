# Polytical Phase 6 — Streaks & Daily Challenge

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Reward daily return. The daily faucet becomes a *streak*: claim on consecutive days and the payout scales; miss a day and it resets. Surface the streak (current + best) on the header faucet and the profile, and highlight a "שוק היום" (market of the day) on the homepage.

**Builds on (do NOT rebuild):** `app/lib/ledger/service.ts` (`claimDailyFaucet`), `app/lib/ledger/repo.ts` (`lockUser`, `setLastFaucetAt`), `app/lib/economy.ts`, `app/lib/schema.ts` (users), `components/faucet-button.tsx`, `app/profile/page.tsx`, `app/actions/faucet.ts`, `app/lib/markets/*`, the design tokens.

**Money-safety invariant (unchanged):** `applyEntry` remains THE sole balance writer. The streak counter + scaled amount are computed UNDER the existing `lockUser` FOR-UPDATE lock, inside the same transaction as the cooldown check — so two concurrent claims can't double-increment or double-pay. The 24h cooldown is preserved (existing tests stay green); streak continuity uses a 48h grace window.

---

## Design — streak model

- **Cooldown:** unchanged — one claim per `FAUCET_COOLDOWN_MS` (24h). Existing faucet tests untouched.
- **Continuity:** on a successful claim, if the previous `lastFaucetAt` was within `STREAK_GRACE_MS` (48h) → the chain continues (`streak += 1`); otherwise it restarts at `1` (first-ever claim also = 1). The 48h grace = "claimed again before a full day lapsed past the cooldown."
- **Bonus:** `amount = DAILY_FAUCET + min(streak - 1, STREAK_BONUS_DAYS) * STREAK_BONUS_PER_DAY`. So day 1 = 200, day 2 = 225, … day 8+ = 375 (capped). Bounded, still `≤ MAX_BALANCE`.
- **Best streak:** `bestStreak = max(bestStreak, streak)` — kept for the profile card.

## Design — market of the day

Read-only. `getMarketOfTheDay` = the open market with the most bets (highest volume); ties → most recent. Rendered as a highlighted "שוק היום" card on the homepage. No coin movement.

## Task 2: Streak-aware faucet (TDD)

**Files:** Modify `app/lib/ledger/repo.ts`, `app/lib/ledger/service.ts`; `app/lib/ledger/service.test.ts`

- [ ] **Step 1:** repo — add `setFaucetClaim({ tx, userId, at, streak, bestStreak })` that updates `lastFaucetAt`, `streakCount`, `bestStreak`, `updatedAt` in one statement (balance still written only by `applyEntry`). Keep `setLastFaucetAt` for back-compat or replace its call sites.
- [ ] **Step 2:** service — `claimDailyFaucet` returns `{ balanceAfter, amount, streak, bonus }`. Under the lock, after the cooldown check:
```ts
const prev = u.lastFaucetAt?.getTime() ?? null;
const now = Date.now();
const continues = prev !== null && now - prev < STREAK_GRACE_MS;
const streak = continues ? u.streakCount + 1 : 1;
const bonus = Math.min(streak - 1, STREAK_BONUS_DAYS) * STREAK_BONUS_PER_DAY;
const amount = DAILY_FAUCET + bonus;
const res = await applyEntry({ tx, userId, type: "faucet", amount });
await repo.setFaucetClaim({ tx, userId, at: new Date(now), streak, bestStreak: Math.max(u.bestStreak, streak) });
return { balanceAfter: res.balanceAfter, amount, streak, bonus };
```
